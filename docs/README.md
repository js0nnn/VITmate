# VITmate Documentation

Technical and research documentation for **VITmate: A Voice-Enabled Deep Learning-Based Campus Assistant for VIT** (B. Jaison Edward, Reg. No. 23BAI0094). For a quick introduction and setup, see the [project README](../README.md).

## Documents

| # | Document | What it contains |
|---|---|---|
| 01 | [Project overview](01-project-overview.md) | Introduction, problem statement, objectives, capabilities, technology stack, development phases, AI-assistance acknowledgement |
| 02 | [System architecture](02-system-architecture.md) | Overall architecture, frontend/backend modules, text-interaction sequence, response-engine decision flow, knowledge data flow, chat persistence, frontend and backend design, design decisions |
| 03 | [Dataset](03-dataset.md) | Sources and licences, analysis of the original dataset, taxonomy (38 intents), cleaning and leakage prevention, dataset v1 → v2 changes, per-intent counts |
| 04 | [Model development](04-model-development.md) | The complete ML story: experiments in order, discarded approaches, the robustness iteration, v2 re-comparison, the inference pipeline and the final model |
| 05 | [Model comparison](05-model-comparison.md) | Baseline vs BERT-mini vs MiniLM-L6 vs bge-small vs DistilBERT, multi-seed results, selection rule, v1 and v2 tables and graphs |
| 06 | [Training methodology](06-training-methodology.md) | Training/evaluation pipeline, hyperparameters, loss, optimizer, early stopping, fp16 storage, threshold selection, reproducibility |
| 07 | [Evaluation](07-evaluation.md) | Metric definitions and final results: test, spoken-style, out-of-scope, threshold sweep, per-intent F1, confusion matrix, latency, memory, error analysis |

| 10 | [Running and deployment](10-deployment.md) | Local setup, reproducing the ML pipeline, configuration, deployment readiness |
| 11 | [Limitations and future work](11-limitations.md) | Known limitations (speech, knowledge, model, app) and planned enhancements |
| 12 | [Results summary](12-results-summary.md) | All key numbers and graphs on one page |
